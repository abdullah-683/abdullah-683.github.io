How I keep 70 jobs honest

A pipeline that fails silently is worse than one that fails loudly. Most of my engineering time goes here.

Retries with a memory

A retry wrapper runs scripts in parallel and logs each one separately, so a flaky API call recovers on its own and leaves a trail.

Schema-locked loads

Dtypes and schemas are enforced before data reaches BigQuery, so an upstream change can't quietly corrupt a table.

Health views

BigQuery views flag stale tables and failed runs, so I hear about a problem before anyone sees a broken dashboard.
